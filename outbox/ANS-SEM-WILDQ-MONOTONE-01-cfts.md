## 先接住v0的自洽首测

## B) 反例与修正

### 反例1：M=0 但不可升级

构造一个**空线**：undecided=0、fail-open=0、FINDING全部闭环、所有卡件带fp、所有ask自包含。

于是 M_line=0。

但这条线**从未被任何波次触达**——它是`v1-draft`的直接产物，没有走过"波次治理→负结果入册→闭环只增不减"这条路径。M1的前提（各波守三即律与负结果入册）**从未被激活**，因此"沿波次非增"是空真，而"刚性态"的语义前提（已经历过至少一轮波次收敛）也不成立。

**结论**：M_line=0 是必要条件，不是充分条件。枢案把"可升级"绑到 M_line=0 上，漏了一个**历程量**：这条线是否至少经历过一轮完整的波次闭环。

### 反例2：M>0 但已刚性

构造一个**冻结线**：某轮波次后 M 降到 0，随后**上游接口被外部锁定**（比如依赖的联邦子项被 mark 为 frozen，或该线被显式 pin 到某个 commit）。

此后新来的 undecided 全部被路由到"挂账"而不计入 M（因为挂账不计入候选单调量的任何子项——这是公式的盲区）。但实际上：
- 线本身**不可再升级**（上游冻结）
- 线本身**已处于刚性语义**（不再接受新波次）

此时 M>0（挂账项在体系里存在，但不进M），而刚性态已达成。

**结论**：M 缺一项——**外部冻结/上游pin**的指示量。它是负向的（冻结⇒M应该被压低或触发刚性），但当前公式里没有任何子项承载它。

### 修正建议

给枢案M加两项：

```
M(W) = α|undecided| + β|fail-open| + γ|未闭环FINDING|
     + δ|无fp卡件| + ε|非自包含ask|
     + ζ·[未经历完整波次闭环]      ← 新增，正值
     - η·[上游冻结/pin]            ← 新增，负值，或作为刚性触发器
```

ζ项解决反例1：M=0但历程未闭环 ⇒ ζ>0 ⇒ M>0 ⇒ 不可升级，正确。
η项解决反例2：M>0但已刚性 ⇒ η足够大时M可被压低，或直接把η作为**刚性触发器**（η>0 ⇒ 刚性，绕过M）。

刚性判据改为：

```
刚性 ⟺ (M=0 ∧ ζ=0) ∨ (η>0)
```

## A) 线-local单调量（接口）

线-local的 M_line 应沿**波次序号**单调，这是M1的线-local版本。等号集不是"M=0"，而是：

```
M_line(n+1) = M_line(n)  ⟺  第n+1波未产生任何新的未闭环项
```

即等号对应"空波"——波次发生但没有引入新债务。这比"M=0"弱得多，也更贴合实际：一条线可以长期处于 M_line=常数>0 的稳定债务态，而不等于它可以升级。

与枢案M的关系：M_line 是 M 在单条线上的投影，但**投影不保持等号集**。枢案的 M=0 是全局条件，线-local的等号是逐波条件。二者是**子项关系但等号集不同**，不能互相推导。

## 一句话总结

枢案M的方向对（非零⇒非刚性），但**双条件右端缺历程量和外部冻结量**。补 ζ（波次闭环经历）和 η（上游冻结）后，M1/M2/M3可以保留，M2的等号集需要重写。
