## 议题一 · 逐项判定

### ① §2.4 退出路径1枚举 B1–B6 漏 B7 → 补正为 B1–B7
**判定：PASS（补正成立，形式性纠错）**

- **理由**：v0.3 已增 B7 触发器，§2.4 枚举未同步，属**枚举遗漏**而非规范冲突。补正为 B1–B7 为闭合性修正，不引入新规范内容。
- **约束**：补正须以「v0.3→v0.5 枚举同步」名义登记，附锚点 diff，禁止借此机会改写 B1–B6 语义。
- **附带指令**：补正后须做一次**枚举-触发器一致性核验**（B1–B7 ↔ 触发器集），防止再次漂移。

### ② §3.2-6 跨案污染 ⇒ REJECTED 系封闭集增录，程序要求判定席确认
**判定：PASS（确认成立，不撤回）**

- **理由**：跨案污染的性质是**受理面瑕疵**，归入 REJECTED 系封闭集符合既有分类逻辑；封闭集增录属程序性扩充，判定席确认即可生效，无需重开 v0.4 全票程序。
- **约束**：增录须**显式登记为封闭集第 n 项**，并注明「仅新增成员，不改封闭性判据」；否则视为隐性扩张，降为 undecided。

### ③ §9 Q6 热轨 DONE 证据模式二选一
**判定：PASS → 选 Q6-b（扩展）**

- **理由**：
  - Q6-a（fallthrough 永不发放热轨 DONE）与 §2.3 合取语义**张力过大**，等于把热轨 DONE 变成不可达态，与 §9 Q6 设立热轨 DONE 的初衷相悖——**fail 方向**。
  - Q6-b 以「捕获 wall + log_digest + §2.4 逐项排除指针」三件套为发放条件，**缺一不发**，保持 §2.3 合取语义不变，属**增量收紧**而非语义改写——**pass 方向**。
- **裁定**：采 **Q6-b**。三件套任一缺失 ⇒ 不发放热轨 DONE，但不升级为 BLOCKED；仅在 DONE 面留缺口，由 §2.4 排除指针回填。
- **附带指令**：Q6-b 生效后须给出**三件套 schema 锚点**（wall 字段名、log_digest 算法、排除指针格式），否则本条为 undecided。

### ④a 全部时刻字段统一 UTC(Z) 单时钟域；非 UTC ⇒ 视同时效字段缺失 ⇒ BLOCKED(B6)
**判定：PASS**

- **理由**：单时钟域是 B6 时效判据的**必要前提**；非 UTC 时间戳在跨案场景下不可比较，视同缺失合理。B6 出口与 §2.4 一致。
- **约束**：须给出**检出规则**（正则/解析器）与**归一化失败路径**（不可解析 vs 可解析但非 Z），二者都归 BLOCKED(B6)，但证据指针须区分。

### ④b §3.1 越权引用与 §3.2-6 污染事件同一违规登记面（统一 schema）
**判定：PASS**

- **理由**：两类事件共享「案id/格id/条款锚/处置级/证据指针」结构，统一 schema 降低登记面分裂风险。schema 字段（事件id/时刻/案id/格id/条款锚/处置级/证据指针）**齐备**。
- **约束**：须明确**处置级枚举**（如 REJECTED / BLOCKED(B2) / BLOCKED(B6)）与**条款锚格式**，否则 schema 不可机检。

### ④c recoverable=false 之格仍属 BLOCKED 机态，不迁移不终态，唯一出口=判定席裁决
**判定：PASS**

- **理由**：与 ④a/④b 的 BLOCKED 语义一致；「不迁移不终态」防止机态被误当终态归档，唯一出口收敛到判定席，避免自动放行。
- **约束**：须在 §2.4 或 §3.2-6 加**交叉引用**，声明 recoverable=false 与 B2/B6 的关系（同格可同时挂 B2 与 B6，不合并）。

### ⑤ 跨案污染时点分界：受理时可识别 ⇒ REJECTED / 受理后识别 ⇒ BLOCKED(B2 同级) + 违规登记
**判定：PASS**

- **理由**：时点分界清晰，与 ② 的封闭集逻辑一致；受理后识别归 BLOCKED(B2 同级) 而非 REJECTED，避免「事后追溯否定受理」的程序倒流。
- **约束**：须定义**「受理时」锚点**（案id 登记时刻 vs 首次格id 绑定时刻），否则分界不可判。

### ⑥ REJECTED 不参与 §8 定序、不构联合态、无计时（确认性补注）
**判定：PASS（确认性补注，非新增规范）**

- **理由**：与 REJECTED 的封闭集性质一致；确认性补注不改变 v0.4 语义，仅显式化。
- **约束**：补注须标注「确认性，非新增」，防止被援引为独立规范。
