## A) 最深映射：第 4 条「刚性等号即分类」——我建议映射到 **fail-closed / 凸性假设 / 单调量等号** 这条链

如果只选五共性中对自家机制最深的一条，我会选：

> **4 刚性等号即分类**：单调量取常数 ⟺ 锥 + 齐次；距离 0 ⟺ 弱同构。

它比第 1 条「耦合为本」更深，因为第 1 条只是说「边缘固定、联合优化」，这是 OT 的定义层；而第 4 条是 **OT 的等号刚性层**：当某个单调量沿优化路径取到等号/常数时，系统不是“更优了一点”，而是 **结构被迫坍缩到某个分类类**。这正好对应贵线里最容易滥级、最容易 fail-open 的地方。

### 机制级对应，不是比喻

| OT 侧机制 | 贵线机制 | 机制级对应 |
|---|---|---|
| 单调性公式：沿最优耦合，某单调量取常数 | fail-closed 的「级名不滥」 | 级名不是标签，而是 **等号刚性见证**；只有某个单调量取等号，才允许升级/命名。否则只能停在低阶协议层。 |
| 凸性 alone 得正则 | 凸性假设作为 fail-closed 闸门 | 凸性不是“优化技巧”，而是 **允许把局部爆破齐次性提升为全局正则** 的充分条件。贵线里对应：只有协议层满足凸性/单调性假设，才允许把局部 CI 通道判定提升为全局等距函子。 |
| 熵惩罚得唯一 | ask 自包含 | 熵惩罚 = 在耦合空间中选唯一极小元；ask 自包含 = 请求本身必须携带足够约束，使解在协议层唯一。否则就是欠定耦合，不能 fail-closed。 |
| 距离 0 ⟺ 弱同构 | fp 互锚 | fp 互锚不是“指纹相同”，而是 **距离泛函为 0 的判定谓词**；距离 0 才允许视为同一弱同构类。否则只是近似，不能互锚。 |
| 切锥局部模型 / N→∞ 涌现 | 尺度爆破 | 局部模型不是缩小版，而是 **爆破极限下的切锥**；对应贵线：小尺度协议失败必须能提升为大尺度切锥分类，否则爆破不收敛。 |

所以第 4 条之所以最深，是因为它把「耦合」「松弛」「最小假设」「爆破」四条都收束到一个可判定谓词上：

> **只有单调量取等号/常数，才允许分类、命名、互锚、升级。**

这正好是 fail-closed 的机制核心：不是“看起来像”，而是“等号成立”。

## B) 一个可操作可判定的「耦合/统一」实验

### 实验名
**UNIFY-OT-EXP-01：凸域耦合等号刚性实验**

### 对象
取两个边缘测度空间：

- \(X = [0,1]^n\)，紧凸域；
- \(\mu, \nu\) 为 \(X\) 上两个绝对连续概率测度，密度有界且正；
- 代价 \(c(x,y) = \frac12 |x-y|^2\)；
- 允许的耦合空间 \(\Pi(\mu,\nu)\)；
- 协议层：固定一族单调量 \(\Phi_k(\pi)\)，例如：
  - 熵 \(H(\pi)\)
  - 二次代价 \(\int c\,d\pi\)
  - 沿 Brenier 势的单调性残差
  - 凸性残差 \(\text{curv}(\pi)\)

### 代价泛函
\[
\mathcal{J}_\lambda(\pi)
=
\int c\,d\pi
+
\lambda H(\pi)
+
\sum_k \alpha_k \Phi_k(\pi)
\]
其中 \(\lambda>0\)，\(\alpha_k\ge 0\)。

- \(\lambda\to 0^+\)：退化为经典 OT；
- \(\lambda>0\)：熵惩罚 OT，解唯一；
- 若凸性假设成立，则 \(\mathcal{J}_\lambda\) 在 \(\Pi(\mu,\nu)\) 上严格凸，极小元唯一。

### 判定谓词
定义等号刚性谓词：

\[
\text{RIGID}(\pi^\star)
\iff
\forall k,\quad
\Phi_k(\pi^\star) = \text{const}_k
\]

并且：

\[
\text{UNIFY}(\mu,\nu)
\iff
\text{RIGID}(\pi^\star)
\land
\text{dist}_0(\pi^\star,\pi_{\text{ref}}) = 0
\]

其中 \(\text{dist}_0\) 是 co-OT 完备测地度量下的距离，\(\pi_{\text{ref}}\) 是参考耦合。

可操作判定：

1. 用 Sinkhorn / entropic OT 求 \(\pi^\star_\lambda\)；
2. 计算所有 \(\Phi_k(\pi^\star_\lambda)\)；
3. 检查是否同时满足：
   - \(\Phi_k\) 在 \(\lambda\) 扫描下取常数；
   - \(\text{dist}_0(\pi^\star_\lambda,\pi^\star_{\lambda'}) = 0\) 对同一弱同构类成立；
   - 凸性残差 \(\le \varepsilon\)。
4. 若成立，输出 `UNIFY=1`，并允许升级/互锚；
5. 否则 `UNIFY=0`，fail-closed，不得升级。

### 预期刚性等号
实验预期出现三类刚性等号：

1. **熵唯一性等号**
   \[
   \lambda>0 \implies \pi^\star_\lambda \text{ 唯一}
   \]
   对应 ask 自包含：请求约束足够强，解唯一。

2. **单调量常数等号**
   \[
   \Phi_k(\pi^\star_\lambda) = \text{const}_k
   \]
   对应级名不滥：只有等号成立，才允许命名/升级。

3. **距离 0 弱同构等号**
   \[
   \text{dist}_0(\pi^\star,\pi_{\text{ref}}) = 0
   \]
   对应 fp 互锚：距离 0 才允许视为同一弱同构类。

如果实验中出现：

- 熵唯一性成立，但单调量不取常数；
- 或距离趋近 0 但不等于 0；
- 或凸性残差超阈值；

则判定为 **耦合失败**，必须 fail-closed，不得进入统一类。

### 一句话总结

- **A**：五共性中第 4 条「刚性等号即分类」最深，因为它把 fail-closed、级名不滥、fp 互锚、ask 自包含全部收束为「单调量取等号才允许分类」。
- **B**：可用「凸域熵惩罚 OT + 单调量常数 + co-OT 距离 0」做可判定实验；预期刚性等号是：熵唯一、单调量常数、距离 0 弱同构。
